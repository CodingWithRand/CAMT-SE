## 0. Main function
ในภาษา Java จะมีโครงสร้างเป็น class ซึ่งชื่อของ class จะตรงกับชื่อไฟล์ java ที่เราสร้าง เช่น ไฟล์ชื่อ App ชื่อ class จะเป็น App มี Syntax ดังนี้
```java
public class App
```
ชื่อ class ควรขึ้นต้นด้วยตัวพิมพ์ใหญ่ ในหนึ่ง class จะมีฟังก์ชัน __main__ ซี่งโค้ด Java จะรันในฟังก์ชัน __main__ นี้
```java
public class App {
    public static void main(String[] args){
        // Code run here
    }
}
```
1 บรรทัดของโค้ดจะเรียกว่า "statement" ซึ่งแต่ละ statement จะต้องลงท้ายด้วย semicolon (;)

## 2. Variable
การประกาศตัวแปร คือการบอกคอมพิวเตอร์ให้เตรียมช่องหน่วยความจำเพื่อที่จะเก็บข้อมูล เมื่อตัวแปรถูกกำหนดค่า ข้อมูลก็จะเข้าไปอยู่ในตัวแปรนั้น <br>
ในการประกาศตัวแปรโดยทั่วไปในภาษาอื่นๆ จะสามารถทำได้ดังนี้
```python
variableName = value
```
แต่การประกาศตัวแปรใน Java จะต้องมีการกำหนดประเภทของตัวแปรด้วย ซึ่งประเภทของตัวแปรที่ใช้บ่อยๆมี int, double, float, String, char
### หลักการประกาศตัวแปรพื้นฐาน
1. ใช้คำที่มีความหมาย
2. ใช้ camelCase (คือคำแรกเป็นตัวพิมพ์เล็กทั้งหมดและคำที่ 2 ขึ้นต้นด้วยตัวพิมพ์ใหญ่)
3. ไม่ตรงกับ keyword/reserved word ของภาษา เช่น class ไม่สามารถเป็นชื่อตัวแปรได้
4. ไม่ขึ้นต้นด้วยตัวเลข แต่ขึ้นต้นด้วย `_` (Underscore) หรือ `$` (Dollar Sign) ได้

### คำอธิบายแต่ละประเภทตัวแปร
* __Integer__ ประเภทตัวแปรใช้กับจำนวนเต็ม
    * __byte__ ช่วงตัวเลข -128 ถึง 127
    * __short__ ช่วงตัวเลข -32678 ถึง 32677
    * __int__ ช่วงตัวเลข 32-bit
    * __long__ ช่วงตัวเลข 64-bit
* __float__ ใช้กับทศนิยม ความแม่นยำถึงทศนิยมตำแหน่งที่ 7 ละเอียดน้อยกว่า
* __double__ ใช้กับทศนิยม ความแม่นยำถึงทศนิยมตำแหน่งที่ 16 ละเอียดกว่า
* __String__ ใช้กับข้อความ
* __char__ ใช้กับตัวอักขระ 1 ตัว

### ตัวอย่างการประกาศตัวแปร
```java
// การประกาศตัวแปรพร้อมให้ค่า
int wholeNumber = 1;
float fractionalNumber = 12.45;
double moreAccurateFractionalNumber = 89.3492;
String text = "Lorem";
char a = 'A'

// การประกาศตัวแปรแบบยังไม่กำหนดค่า (ต้องกำหนดทีหลัง)
int wholeNumber;
float fractionalNumber;
double moreAccurateFractionalNumber;
String text;
char a;
// กำหนดทีหลัง
wholeNumber = 1;
fractionalNumber = 12.45;
moreAccurateFractionalNumber = 89.3492;
text = "Lorem";
a = 'A'
```

```java

```
### Constant Variable
ประกาศตัวแปรคงที่ ซึ่งตัวแปรประเภทนี้จะไม่สามารถเปลี่ยนแปลงค่าได้ หลังจากกำหนดค่าแล้วรอบนึง หลักการทั่วไปของการตั้งชื่อตัวแปรคือ ใช้ตัวพิมพ์ใหญ่ล้วนและขั้นคำด้วย `_`
```java
final float FLOORED_THREEDECIMALPOINT_PI = 3.141; // ประกาศพร้อมกำหนด
final int SLIDE_NUMBERS; // ประกาศก่อน
SLIDE_NUMBERS = 4; // กำหนดทีหลัง
```

### การทำ Type Casting
คือการเปลี่ยนประเภทของข้อมูล เช่น จาก int เป็น double หรือจาก double เป็น int แต่สำหรับบางประเภทไม่จำเป็นต้อง cast (เพราะแปลงให้แล้วอัตโนมัติ เช่น int -> double) หรือบางประเภท cast ไม่ได้ (String -> char / char -> String)
```java
double d = 6.0;

int i = d;
// ❌ ไม่สามารถทำได้ เพราะประเภทตัวแปรของทั้ง 2 ตัวแปรต่างกัน ต้องทำการเปลี่ยนประเภทตัวแปรก่อนโดยการ type casting

int i = (int) integer;
// ✅ ทั้ง 2 ข้างของ "=" เป็นประเภทข้อมูลเดียวกันแล้ว
```

### Literal
พูดง่ายๆ คือ(ประเภท)ข้อมูลที่ถูกกำหนดในตัวแปร ซึ่งต้องตรงกับประเภทของตัวแปร
```java
String text = "text"; // String Literal
int rand0mNumber = 14462332562; // Int Literal
```
ใน Java ประเภทของข้อมูลจำนวนเต็มโดยดั้งเดิมคือ `int` และประเภทของข้อมูลเลขทศนิยมโดยดั้งเดิมคือ `double` 
- ในการกำหนดตัวแปรประเภท `long` บางครั้งอาจมีการกำหนดตัวเลขที่มีค่าเกินกว่า `int` จะรับได้ (32-bit ≈ 2 พันล้าน) ดังนั้นจึงต้องใส่ `L` หรือ `l` ต่อท้ายตัวเลขขณะกำหนดค่าตัวแปรประเภท `long` ด้วย (คล้ายๆ กับ cast เป็น `long`)
- สำหรับข้อมูลประเภท `double` มีค่าความแม่นยำที่ทศนิยม 16 ตำแหน่ง ซึ่งละเอียดกว่า `float` จึงต้องทำการแปลงประเภทข้อมูลให้เป็น `float` โดยการเติม `F` หรือ `f` ต่อท้ายก่อน (เหมือนกับ cast เป็น `float`) แล้วจึงจะกำหนดค่าให้กับตัวแปรประเภท `float` ได้
- สามารถเติม `D` หรือ `d` ต่อท้ายในการประกาศตัวแปรประเภท `double` ได้เช่นกัน แต่ไม่จำเป็น
```java
long mathHuge = 21474836480; // ❌ ไม่สามารถทำได้ เพราะค่าตัวเลขนี้อยู่นอกขอบเขตค่าของ int
long mathHuge = 21474836480L; // ✅ ต้องทำแบบนี้ (ควรใช้ L พิมพ์ใหญ่เพื่อไม่ให้สับสนกับ I หรือ 1)
float highPrecisionPi = 3.14159265358979323846; // ❌ ไม่สามารถทำได้ เพราะความละเอียดของข้อมูลจะสูญเสียไป
float highPrecisionPi = 3.14159265358979323846f; // ✅ ต้องทำแบบนี้ หรือ cast เป็น float แต่ยังไงความละเอียดของข้อมูลก็จะสูญเสียอยู่ดี
double e = 2.718281828 // ✅ ทำแบบนี้ได้
double e = 2.718281828D // ✅ ทำแบบนี้ได้เช่นกัน
```

## 3. Import and Scanner
ถ้าอยากให้โปรแกรมสามารถรับข้อมูลจากผู้ใช้ใน Java เราจะใช้ class Scanner ซึ่ง Scanner นี้จะต้องนำเข้ามาจาก package อื่นๆ โดยการ import
```java
// การนำเข้า class Scanner
import java.util.Scanner;
```
จากนั้นเราจะสร้างตัวแปรสำหรับการรับค่า เราจะใช้ชื่อ "input" เป็นค่าเริ่มต้นเพื่อความเข้าใจ
```java
Scanner input = new Scanner(System.in);
```
ในการรับค่า เราจะใช้คำสั่งจาก input ตามนี้
```java
input.nextLine(); //รับค่า String (หยุดรับเมื่อกด enter) 
input.next(); //รับค่า String (หยุดรับเมื่อมี white space แต่เรายังพิมพ์ข้อความต่อได้ จนกว่าจะ enter)
input.nextByte(); //รับค่า byte
input.nextShort(); //รับค่า short
input.nextInt(); //รับค่า int
input.nextLong(); //รับค่า long
input.nextDouble(); //รับค่า double
input.nextFloat(); //รับค่า float
```
สำหรับ char เราไม่สามารถใช้ฟังก์ชันจาก input โดยตรงได้ จะต้องรับค่าเป็น String ก่อนแล้วเปลี่ยนเป็น char โดยใช้คำสั่ง charAt()
```java
String str = input.nextLine();
char c = str.charAt(0);
```

## 4. Math operators
การดำเนินการทางคณิตศาสตร์ จะมีเครื่องหมายดังนี้
* \+ คือการบวก
* \- คือการลบ
* \* คือการคูณ
* / คือการหาร
* % คือการหารเอาเศษ (mod)

ลำดับของการดำเนินการคือ ทำในวงเล็บก่อน ทำคูณหารและ mod ก่อนบวกลบ และทำจากซ้ายไปขวา
### ข้อควรระวัง
ในการหาร ถ้าหากประเภทของข้อมูลเป็นจำนวนเต็ม (int) หารด้วยจำนวนเต็ม (int) จะให้ผลลัพธ์เป็นจำนวนเต็ม (int) เท่านั้น หากผลลัพธ์มีทศนิยม จะถูกปัดทศนิยมทิ้ง (floor) ดังนั้นถ้าอยากหารให้ได้ทศนิยม จะต้องทำให้จำนวนเต็มตัวใดตัวหนึ่งเป็นทศนิยมโดยการเติม ".0" เข้าไป
```java
// ตัวอย่าง
5/2 = 2 // 5 เป็น int, 2 เป็น int ผลลัพธ์จึงออกมาเป็น 2 (int)
5.0/2 = 2.5 // 5.0 เป็น double, 2 เป็น int ผลลัพธ์จึงออกมาเป็น 2.5 (double)
5/2.0 = 2.5 // 5 เป็น int, 2.0 เป็น double ผลลัพธ์จึงออกมาเป็น 2.5 (double)
```

### Assignment Operators
คือเอาตัวดำเนินการทางคณิตศาสตร์มาต่อกับ `=` ใช้สำหรับกำหนดค่าพร้อมกับหลังจากได้ดำเนินการทางคณิตศาสตร์แล้ว
```java
int x = 4;
x += 4; // x = x + 4
//ตอนนี้ x มีค่าเท่ากับ 8
```

### Preincrement and Postincrement
- Preincrement จะเพิ่มค่าให้กับตัวแปรไป 1 และแสดงผลเป็นค่าที่เพิ่มแล้ว
- Postincrement จะเพิ่มค่าให้กับตัวแปรไป 1 แต่ยังแสดงผลเป็นค่าเดิมอยู่
```java
// ตัวอย่าง
int x = 5;

System.out.println(x++) // จะแสดงผลเป็น 5 แต่ค่าตัวแปรจริงๆเป็น 6 แล้ว
System.out.println(x) // เมื่อ print อีกครั้งถึงจะแสดงค่าเป็น 6

int y = 10;

System.out.println(++y) // ค่าในตัวแปรเพิ่มขึ้น 1 เป็น 11 พร้อมกับแสดงผล 11 ออกมา
```

### คำสั่งอื่นๆที่เกี่ยวข้อง

## 5.1 If-Else
ใช้ในการตรวจสอบเงื่อนไขว่าเป็นจริงหรือไม่ หากเป็นจริง ให้รันโค้ดต่อไป
```java
if(condition){
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) เป็นจริง
}
```
สำหรับ else จะใช้ต่อจาก if ในกรณีที่เงื่อนไขไม่เป็นจริง
```java
if(condition){
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) เป็นจริง
}else{
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) ไม่เป็นจริง
}
```
ในกรณีที่แต่ละ block มี statement เดียว สามารถละ `{` กับ `}` ได้
```java
if(condition) /* โค้ดที่จะรันเมื่อเงื่อนไข (condition) เป็นจริง, 1 statement*/;
else /* โค้ดที่จะรันเมื่อเงื่อนไข (condition) ไม่เป็นจริง, 1 statement */;
```
### Conditional Operator
การเขียนแบบย่อด้วย `?` กับ `:`
```java
condition ? valueWhenTrue : valueWhenFalse
```
หาก condition เป็นจริง โดยผลลัพธ์จาก statement นี้จะเป็น valueWhenTrue หาก condition เป็นเท็จ ผลลัพธ์จาก statement นี้จะเป็น valueWhenFalse


## 5.2 Condition
เงื่อนไขจะให้ผลลัพธ์เป็น จริง (True) หรือ เท็จ (False) ในการสร้างเงื่อนไข (condition) จะมีตัวดำเนินการต่างๆ แบ่งเป็น 2 ส่วนคือ ตัวดำเนินการเปรียบเทียบ กับตัวดำเนินการทางตรรกศาสตร์
### ตัวดำเนินการเปรียบเทียบ
* \> มากกว่า
* < น้อยกว่า
* \>= มากกว่าเท่ากับ
* <= น้อยกว่าเท่ากับ
* == เท่ากับ
* != ไม่เท่ากับ
### ตัวดำเนินการทางตรรกศาสตร์
* && และ (AND)
* || หรือ (OR)
* ^ (XOR) จะให้ค่าเป็นจริงก็ต่อเมื่อค่าความจริงทั้ง 2 ฝั่งต่างกันเท่านั้น เช่น True ^ False = True
* ! นิเสธ (Negate / NOT)

จากหัวข้อ [Variable](#2-variable) ผลลัพธ์ของเงื่อนไขที่เป็นค่าความจริงสามารถกำหนดใส่ตัวแปรได้ โดยประเภทของตัวแปรจะเป็น boolean
```java
int x = 20;
boolean trueValue = true; // กำหนดตัวแปรมีค่าความจริงเป็นจริง
boolean condition = x > 25; 
// กำหนดตัวแปรมีค่าความจริงตามเงื่อนไขที่ใส่เข้าไป จากตัวอย่าง x ซึ่งเท่ากับ 20 ไม่ได้มีค่ามากกว่า 25 ดังนั้น ค่าตัวแปร condition จึงจะเป็น false
String b = (x > 25) ? "Greater than 25" : "Less than 25";
```

## 6. Switch-Case
```java
switch(value){
    case 1:
        // Statement
        break;
    case '2':
        // Statement
        break;
    default:
        // Default statement
}
```
`switch` จะทำการรับข้อมูลจากค่า `value` ที่ป้อน แล้วนำมาเปรียบเทียบกับค่าแต่ละค่าใน `case` หากค่าตรงกันแล้วให้ทำ code ใน case นั้นต่อ แต่ที่สำคัญคือต้องมี `break` เพราะไม่งั้น code ใน `case` ต่อๆไปจะทำงานได้

แต่การใช้งานอีกแบบหนึ่ง คือในกรณีที่หลายๆ case ต้องการให้ run code เดียวกัน สามารถทำแบบนี้ได้
```java
switch(value){
    case 1: case 2: case 3:
        // โค้ดในกรณีที่ value มีค่าเป็น 1,2 หรือ 3
        break;
    case 4: case 5:
        // โค้ดในกรณีที่ value มีค่าเป็น 4 หรือ 5
        break;
    default:
        // Default statement
}
```

`default` case เป็น case ที่เอาไว้รองรับในกรณีที่ค่า value ไม่ตรงกับค่าใดสัก `case` ใน `switch` โค้ดใน `default` จะ run

**Note** ค่าที่ใส่ให้ switch ตรวจสอบ ควรเป็น `char` (`String`), `byte`, `short`, `int`. `double` จะไม่สามารถตรวจสอบกับ `case` ต่างๆ ได้
