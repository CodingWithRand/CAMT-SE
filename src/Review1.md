## 0. Main function
ในภาษา Java จะมีโครงสร้างเป็น class ซึ่งชื่อของ class จะตรงกับชื่อไฟล์ java ที่เราสร้าง เช่น ไฟล์ชื่อ App ชื่อ class จะเป็น App มี Syntax ดังนี้
```java
public class App
```
ในหนึ่ง class จะมีฟังก์ชัน __main__ ซี่งโค้ด Java จะรันในฟังก์ชัน __main__ นี้
```java
public class App {
    public static void main(String[] args){
        // Code run here
    }
}
```
1 บรรทัดของโค้ดจะเรียกว่า "statement" ซึ่งแต่ละ statement จะต้องลงท้ายด้วย semicolon (;)

## 2. Variable
ในการประกาศตัวแปรโดยทั่วไปในภาษาอื่นๆ จะสามารถทำได้ดังนี้
```python
variableName = value
```
แต่การประกาศตัวแปรใน Java จะต้องมีการกำหนดประเภทของตัวแปรด้วย ซึ่งประเภทของตัวแปรที่ใช้บ่อยๆมี int, double, float, String, char
### หลักการประกาศตัวแปรพื้นฐาน
1. ใช้คำที่มีความหมาย
2. ใช้ camelCase (คือคำแรกเป็นตัวพิมพ์เล็กทั้งหมดและคำที่ 2 ขึ้นต้นด้วยตัวพิมพ์ใหญ่)
3. ไม่ตรงกับ keyword ของภาษา เช่น class ไม่สามารถเป็นชื่อตัวแปรได้

### คำอธิบายแต่ละประเภทตัวแปร
* __int__ ใช้กับจำนวนเต็ม
* __float__ ใช้กับทศนิยม ความแม่นยำถึงทศนิยมตำแหน่งที่ 7
* __double__ ใช้กับทศนิยม ความแม่นยำถึงทศนิยมตำแหน่งที่ 16
* __String__ ใช้กับข้อความ
* __char__ ใช้กับตัวอักขระ 1 ตัว

### ตัวอย่างการประกาศตัวแปร
```java
// การประกาศตัวแปรพร้อมให้ค่า
int wholeNumber = 1;
float fractionalNumber = 12.45;
double moreAccurateFractionalNumber = 89.3492;
String text = "Lorem";
char a = 'A'

// การประกาศตัวแปรแบบยังไม่กำหนดค่า (ต้องกำหนดทีหลัง)
int wholeNumber;
float fractionalNumber;
double moreAccurateFractionalNumber;
String text;
char a;
// กำหนดทีหลัง
wholeNumber = 1;
fractionalNumber = 12.45;
moreAccurateFractionalNumber = 89.3492;
text = "Lorem";
a = 'A'
```

จากหัวข้อ [Print](#1-print)
เราสามารถใช้เครื่องหมาย "+" ในวงเล็บ เพื่อเชื่อมค่าตัวแปรกับข้อความได้ เช่น
```java
System.out.println("Result: " + result)
```
### การทำ Type Casting
คือการเปลี่ยนประเภทของข้อมูล เช่น จาก int เป็น double หรือจาก double เป็น int
```java
double d = 6.0;

int i = d;
// ❌ ไม่สามารถทำได้ เพราะประเภทตัวแปรของทั้ง 2 ตัวแปรต่างกัน ต้องทำการเปลี่ยนประเภทตัวแปรก่อนโดยการ type casting

int i = (int) integer;
// ✅ ทั้ง 2 ข้างของ "=" เป็นประเภทข้อมูลเดียวกันแล้ว
```

## 3. Import and Scanner
ถ้าอยากให้โปรแกรมสามารถรับข้อมูลจากผู้ใช้ใน Java เราจะใช้ class Scanner ซึ่ง Scanner นี้จะต้องนำเข้ามาจาก package อื่นๆ โดยการ import
```java
// การนำเข้า class Scanner
import java.util.Scanner;
```
จากนั้นเราจะสร้างตัวแปรสำหรับการรับค่า เราจะใช้ชื่อ "input" เป็นค่าเริ่มต้นเพื่อความเข้าใจ
```java
Scanner input = new Scanner(System.in);
```
ในการรับค่า เราจะใช้คำสั่งจาก input ตามนี้
```java
input.nextLine(); //รับค่า String
input.nextInt(); //รับค่า int
input.nextDouble(); //รับค่า double
input.nextFloat(); //รับค่า float
```
สำหรับ char เราไม่สามารถใช้ฟังก์ชันจาก input โดยตรงได้ จะต้องรับค่าเป็น String ก่อนแล้วเปลี่ยนเป็น char โดยใช้คำสั่ง charAt()
```java
String str = input.nextLine();
char c = str.charAt(0);
```

## 4. Math operators
การดำเนินการทางคณิตศาสตร์ จะมีเครื่องหมายดังนี้
* \+ คือการบวก
* \- คือการลบ
* \* คือการคูณ
* / คือการหาร
* % คือการหารเอาเศษ (mod)

ลำดับของการดำเนินการคือ ทำในวงเล็บก่อน ทำคูณหารและ mod ก่อนบวกลบ และทำจากซ้ายไปขวา
### ข้อควรระวัง
ในการหาร ถ้าหากประเภทของข้อมูลเป็นจำนวนเต็ม (int) หารด้วยจำนวนเต็ม (int) จะให้ผลลัพธ์เป็นจำนวนเต็ม (int) เท่านั้น หากผลลัพธ์มีทศนิยม จะถูกปัดทศนิยมทิ้ง (floor) ดังนั้นถ้าอยากหารให้ได้ทศนิยม จะต้องทำให้จำนวนเต็มตัวใดตัวหนึ่งเป็นทศนิยมโดยการเติม ".0" เข้าไป
```java
// ตัวอย่าง
5/2 = 2 // 5 เป็น int, 2 เป็น int ผลลัพธ์จึงออกมาเป็น 2 (int)
5.0/2 = 2.5 // 5.0 เป็น double, 2 เป็น int ผลลัพธ์จึงออกมาเป็น 2.5 (double)
5/2.0 = 2.5 // 5 เป็น int, 2.0 เป็น double ผลลัพธ์จึงออกมาเป็น 2.5 (double)
```
### Preincrement and Postincrement
- Preincrement จะเพิ่มค่าให้กับตัวแปรไป 1 และแสดงผลเป็นค่าที่เพิ่มแล้ว
- Postincrement จะเพิ่มค่าให้กับตัวแปรไป 1 แต่ยังแสดงผลเป็นค่าเดิมอยู่
```java
// ตัวอย่าง
int x = 5;

System.out.println(x++) // จะแสดงผลเป็น 5 แต่ค่าตัวแปรจริงๆเป็น 6 แล้ว
System.out.println(x) // เมื่อ print อีกครั้งถึงจะแสดงค่าเป็น 6

int y = 10;

System.out.println(++y) // ค่าในตัวแปรเพิ่มขึ้น 1 เป็น 11 พร้อมกับแสดงผล 11 ออกมา
```

### คำสั่งอื่นๆที่เกี่ยวข้อง
```java
Math.pow(x,y) // คือการยกกำลัง จากโค้ด แปลงได้เป็น x^y
Math.PI // ค่าพาย
Math.sqrt(x) // ค่า square root ของ x
```

## 5.1 If-Else
ใช้ในการตรวจสอบเงื่อนไขว่าเป็นจริงหรือไม่ หากเป็นจริง ให้รันโค้ดต่อไป
```java
if(condition){
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) เป็นจริง
}
```
สำหรับ else จะใช้ต่อจาก if ในกรณีที่เงื่อนไขไม่เป็นจริง
```java
if(condition){
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) เป็นจริง
}else{
    // โค้ดที่จะรันเมื่อเงื่อนไข (condition) ไม่เป็นจริง
}
```

## 5.2 Condition
เงื่อนไขจะให้ผลลัพธ์เป็น จริง (True) หรือ เท็จ (False) ในการสร้างเงื่อนไข (condition) จะมีตัวดำเนินการต่างๆ แบ่งเป็น 2 ส่วนคือ ตัวดำเนินการเปรียบเทียบ กับตัวดำเนินการทางตรรกศาสตร์
### ตัวดำเนินการเปรียบเทียบ
* \> มากกว่า
* < น้อยกว่า
* \>= มากกว่าเท่ากับ
* <= น้อยกว่าเท่ากับ
* == เท่ากับ
* != ไม่เท่ากับ
### ตัวดำเนินการทางตรรกศาสตร์
* && และ (AND)
* || หรือ (OR)
* ^ (XOR) จะให้ค่าเป็นจริงก็ต่อเมื่อค่าความจริงทั้ง 2 ฝั่งต่างกันเท่านั้น เช่น True ^ False = True
* ! นิเสธ (Negate / NOT)

จากหัวข้อ [Variable](#2-variable) ผลลัพธ์ของเงื่อนไขที่เป็นค่าความจริงสามารถกำหนดใส่ตัวแปรได้ โดยประเภทของตัวแปรจะเป็น boolean
```java
int x = 20;
boolean trueValue = true; // กำหนดตัวแปรมีค่าความจริงเป็นจริง
boolean condition = x > 25; 
// กำหนดตัวแปรมีค่าความจริงตามเงื่อนไขที่ใส่เข้าไป จากตัวอย่าง x ซึ่งเท่ากับ 20 ไม่ได้มีค่ามากกว่า 25 ดังนั้น ค่าตัวแปร condition จึงจะเป็น false
```
