Terminologies
Repository: Your project folder
Branch: Your separate workspace
Remote: Your remote repository. In this case, it's GitHub copy of your repo
Commit: A snapshot of your changes
Merge: Combine branches together

Actually, you can use vscode for doing these git actions but here are the cli commands anyway.
CLI Commands
> git init                                          # Initialize git.
> git add .                                         # Add everything in the current folder. And stage the changes, waiting to be commited.
> git add file.txt                                  # Add a specific file
> git add folder/                                   # Add everything in `folder`
> git rm file.txt                                   # Remove a specific file, and unstage it. (--cached to just unstage it)
> git commit -m "commit message here"               # Commit with comments (Required); Save snapshot in the local repository
> git remote -v                                     # Check your remote repo that link with github.
> git remote add origin <your-github-repo-link>     # Add remote repo name origin
> git remote remove origin                          # Remove remote repo name origin
> git push -u origin main                           # Upload your local repository to remote repository on GitHub (branch: main)
Note: -u flag means set the upstream remote and branch as the default one, so next time you can just do `git push`/`git pull`
> git pull                                          # Download remote repository to local repository (Update)
> git reset HEAD~1                                  # Revert one commit
> git status                                        # Show the current status for changes on each file.
> git branch                                        # Show available branches
> git clone <github-repo-link>                      # Download remote repository with specified link

YOU NEED TO PULL BEFORE PUSH IF THERE'S A CHANGE IN THE REMOTE REPO!!!
